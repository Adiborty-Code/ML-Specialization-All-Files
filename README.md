# Machine Learning Specialization

This repository contains all the files, notes, and code used while completing the **"Machine Learning Specialization"** course on Coursera.

## About the Course

This specialization provides a comprehensive introduction to modern machine learning, covering both theory and practical implementation. Topics include:

- **Supervised Learning** - Regression and classification algorithms
- **Advanced Learning Algorithms** - Neural networks and decision trees
- **Unsupervised Learning** - Clustering, anomaly detection, and recommender systems
- **Reinforcement Learning** - Fundamentals and applications

## Technologies Used

- Python
- NumPy
- Scikit-learn
- TensorFlow
- Matplotlib
- Jupyter Notebooks

## Course Information

- **Platform**: Coursera
- **Specialization**: Machine Learning Specialization
- **Offered by**: DeepLearning.AI & Stanford University
- **Instructor**: Andrew Ng
